# FlowPilot

## Agentic Workflow Automation Platform

FlowPilot is an agentic workflow automation platform that autonomously
executes employee onboarding workflows using LangGraph, MCP, Groq,
PostgreSQL, Redis, and policy-grounded RAG.

## Tech Stack

- FastAPI
- PostgreSQL
- Redis
- LangGraph
- MCP
- Groq
- pgvector
- JWT + RBAC
- Next.js
- Docker
